# T01 — Persistent relation across source states

- **Operation under test:** `getRelationStateAtTime`
- **Conformance classes:** Temporal Grounding, Query API
- **Competency questions:** CQ3, CQ5
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T01-persistent-relation`

## Ontological property

Persistence is a **computed** property of evidence admissibility, not a stored interval. A
relation remains `supported` across successive source states because a supporting evidence
basis is admissible throughout — never because a validity interval was copied onto it.

## Scenario

An affirmative relation is supported by evidence anchored to an evidence unit whose owning
source state remains admissible across two successive source states, S1 (earlier) and S2
(later).

## Required invariants

1. A supporting evidence basis is admissible across the successive source states.
2. The relation is `supported` at query times within each state's window.
3. No authoritative interval is copied onto the `DerivedRelation`.

## Expected behavior

`getRelationStateAtTime` returns `state = supported` at a query time in each successive
source-state window, computed from evidence admissibility under the profile.
