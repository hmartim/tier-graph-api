# T10 — Anachronistic path exclusion

- **Operation under test:** `findAdmissiblePaths` (with `explainPathExclusion`)
- **Conformance classes:** Path
- **Competency questions:** CQ7, CQ8
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T10-anachronistic-path`

## Ontological property

Paths are generated over the **time-indexed projection**. Two relations that each existed at
*some* time but never at the *same* time MUST NOT form a path for any single query time —
excluding such paths requires projection-first traversal, not post-hoc filtering (no
**temporal-topology leakage**; [spec/08](../../spec/08-paths-and-temporal-topology.md)).

## Scenario

Relation `r1` is admissible only in window `W1`; relation `r2` only in window `W2`, with
`W1 ∩ W2 = ∅`. A caller searches for a path from the source of `r1` to the target of `r2` at
a query time in `W1`.

## Required invariants

1. Two relations that are not co-admissible at the query time do not form a path.
2. Candidate generation is constrained by the time-indexed projection.
3. No post-hoc-only temporal filtering of an all-time traversal.

## Expected behavior

`findAdmissiblePaths` returns no path chaining `r1` and `r2` at a query time where they are
not co-admissible; `explainPathExclusion` names the inadmissible step(s).
