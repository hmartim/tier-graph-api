# T04 — Withdrawn historical precondition

- **Operation under test:** `getRelationStateAtTime`
- **Conformance classes:** Temporal Grounding, Query API
- **Competency questions:** CQ3, CQ6
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T04-withdrawn-precondition`

## Ontological property

Historical evidence is **retained**; a relation's state changes when a precondition's
evidence ceases to be admissible. Models e.g. the historical removal of a precondition.

## Scenario

A relation is supported while a precondition's evidence is admissible. At boundary `b` the
precondition's owning source state ceases to be admissible.

## Required invariants

1. Historical evidence is retained (not deleted).
2. The relation is `supported` before the boundary.
3. The relation is `unsupported` after the boundary.
4. No authoritative interval is copied onto the `DerivedRelation`.

## Expected behavior

`getRelationStateAtTime` returns `supported` before the withdrawal boundary and
`unsupported` after it, while the historical evidence remains queryable.
