# T09 — Prospective applicability (deferred effect)

- **Operation under test:** `evaluateSourceStateAdmissibility`
- **Conformance classes:** Temporal Grounding
- **Competency questions:** CQ3
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T09-vacatio-applicability`

## Ontological property

A source state that is **published but not yet effective** (a deferred-effect / vacatio
window) is inadmissible until its effect begins. Existence of the source earlier does not
imply admissibility.

## Scenario

A source state exists from time `p` (publication) but is effective only from `e > p`.

## Required invariants

1. The source state is inadmissible for query times in `[p, e)`.
2. It becomes admissible at and after `e`.
3. Earlier existence does not imply admissibility.

## Expected behavior

`evaluateSourceStateAdmissibility` returns `admissible = false` before the effective boundary
`e` and `admissible = true` at/after it.
