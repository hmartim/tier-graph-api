# T02 — Later introduction of a relation

- **Operation under test:** `getRelationStateAtTime`
- **Conformance classes:** Temporal Grounding, Query API
- **Competency questions:** CQ3, CQ6
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T02-later-introduction`

## Ontological property

A relation's start is a **computed boundary**, derived from when its supporting evidence's
source state becomes admissible — not a stored start date.

## Scenario

A relation's only supporting evidence is owned by a source state that becomes admissible at
time `b`. Before `b` there is no admissible support.

## Required invariants

1. Before `b`, the relation is `unsupported`.
2. At and after `b`, the relation is `supported`.
3. The transition boundary is derived from admissibility, not stored.

## Expected behavior

`getRelationStateAtTime` returns `unsupported` before the boundary and `supported` at/after
it.
