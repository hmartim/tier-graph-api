# T05 — Composite cross-item evidence

- **Operation under test:** `evaluateEvidenceAdmissibility`
- **Conformance classes:** Core Model, Temporal Grounding
- **Competency questions:** CQ2, CQ3
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T05-composite-cross-item-support`

## Ontological property

Anchors within one `RelationEvidence` record are **conjunctive**: one inadmissible anchor
sinks the whole basis.

## Scenario

A single `RelationEvidence` record has conjunctive anchors to evidence units owned by
**different** source states, S_a and S_b. At the query time, S_a is admissible but S_b is
not.

## Required invariants

1. The record's anchors are conjunctive across units owned by different source states.
2. The basis is admissible **only** when all anchors' owning source states are admissible.
3. Per-anchor detail is reported (`anchorResults`).

## Expected behavior

`evaluateEvidenceAdmissibility` returns `admissible = false` when any anchor is inadmissible,
with anchor-level detail identifying the failing anchor.
