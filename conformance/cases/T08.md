# T08 — Re-extraction without duplicate evidence

- **Operation under test:** `createEvidence`
- **Conformance classes:** Authoring, Core Model
- **Competency questions:** CQ2
- **Executable fixture:** `tier-graph-reference` → `fixtures/cases/T08-reextraction-no-duplication`

## Ontological property

Re-extraction with the same `EvidenceKey` (relation, anchors — each with its optional
selector — and stance) appends a
`ProvenanceActivity`; it does **not** create a new independent `RelationEvidence`
([spec/04](../../spec/04-evidence-semantics.md#44-evidence-identity)).

## Scenario

An evidence occurrence exists. A pipeline re-runs over the same relation, anchors,
selectors, and stance.

## Required invariants

1. Re-running with the same `EvidenceKey` does not create a new `RelationEvidence`.
2. A new `ProvenanceActivity` is appended to the existing occurrence.
3. The independent-evidence count is not inflated.

## Expected behavior

`createEvidence` with a duplicate `EvidenceKey` is detected (`409`/flagged); the occurrence
gains a provenance activity rather than a duplicate evidence record.
